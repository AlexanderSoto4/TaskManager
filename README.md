# TaskManager
English: 
A task manager programmed in c++ that lets you adjust the priority of the task and display a summary of the task with details such as the due date, the tittle and a brief description

Español:
Un gestor de tareas programado en C++ que permite ajustar la prioridad de la tarea y mostrar un resumen de la misma con detalles como la fecha de entrega, el título y una breve descripción.
